## Installation

1. Install [Plutonium](https://plutonium.pw) and run it once so its folders exist, then close it.
2. [Download the mod manager](https://github.com/DavidHiFi/QualityOfLifeModManager/releases/latest). `QualityOfLifeModManagerSetup.exe` installs it, or unzip `QualityOfLifeModManager-portable.zip` and run it from there.
3. Open it, choose **Quality of Life** in the sidebar, and press **Install** on the mod you want.

Prefer to do it by hand? Each mod's own README has the manual steps, and those also work on Linux through Wine, Proton, Lutris and Bottles.

## What the mods add

Black Ops II has all of these today, and the other mods will follow the same ideas:

- **Settings menu:** toggle mechanics, gameplay rules, HUD and audio in game, without console commands.
- **More weapons:** Campaign and Multiplayer guns in the Mystery Box.
- **Bonus Survival maps:** playable areas the original games never shipped as their own maps.
- **Fixes:** the small annoyances the base games left in.
- **Chat commands:** give weapons, change rounds and more, bindable to keys.

Each mod's README has its real feature list.

## Mod manager

[**Quality of Life Mod Manager**](https://github.com/DavidHiFi/QualityOfLifeModManager) is the easy way to install any mod on this page. It runs on Windows 10 and 11.

- **Series mods:** install, update and remove each one, plus the Black Ops II HD textures, custom sounds and controller icons.
- **Other mods:** manage everything in your Plutonium folders. Drop a zip, rar or 7z, or paste a GitHub link, and uninstall restores what it replaced.
- **Community mods:** browse a catalog with cover art and see what you already have.
- **Play:** launch in LAN with the mod loaded, or online through Plutonium's launcher.
- **ReShade:** keeps your colour grading in place while you play.
- **LAN server:** start and stop a dedicated server.
