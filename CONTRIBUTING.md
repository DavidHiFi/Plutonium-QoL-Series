# Contributing to the Quality Of Life Series

Thanks for helping. This repository is the landing page for the series. The mods and the mod manager live in their own repositories, so bugs in them go there:

- [T6-QoL](https://github.com/DavidHiFi/T6-QoL/issues/new) for Black Ops II
- [QualityOfLifeModManager](https://github.com/DavidHiFi/QualityOfLifeModManager/issues/new) for the mod manager

## Reporting a problem with this page

[Open an issue](https://github.com/DavidHiFi/Plutonium-QoL-Series/issues/new) and include the link or line that is wrong and what it should say instead.

## Suggesting a change

Open an issue that describes what you want to change and why. Clearer wording for new players is always welcome.

## Sending a pull request

1. Fork the repo and create a branch from `main`.
2. There is nothing to install or build. The repo is `README.md` and this file.
3. Before you push, open every link you changed in a private browser window, and check that each mod's status matches its own repository.
4. Keep each pull request to one change, and say in the description what you checked.
