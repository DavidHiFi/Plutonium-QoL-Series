# Contributing

Thanks for helping the Quality of Life series. This repository is the landing page for the series; the mods live in their own repositories.

## Ways to help

- Report broken links or outdated descriptions
- Suggest wording that makes the series easier to understand
- Point new players at the right mod repository

## Getting set up

No build step. The page links to the T4, T5, T6 and T7 repositories and to the Quality of Life mod manager.

## Checks before a pull request

- Check every link in a private browser window
- Keep descriptions in step with the mod repositories

## Where to submit

Open issues and pull requests in this repository.
